# 005: Easy words on screen

**Status:** accepted

Everything people read should use simple English. Some words on screen are different from the names in the code:

| In the code and database | On screen       |
| ------------------------ | --------------- |
| `screening`              | First round     |
| `withdrawn`              | Dropped         |
| application, tracker     | Job, board      |
| response rate            | Reply rate      |
| funnel                   | How far you got |
| pipeline stage           | Step            |
| rejected (hiring)        | Not selected    |
| open job                 | Live            |
| scorecard                | Score           |
| assign                   | Give to         |

The code keeps the normal hiring words, so the API stays the same if the screen words change.
